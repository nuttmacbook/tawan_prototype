# สถานะตอนนี้

> ระบบอัปเดตไฟล์นี้เอง แก้ตัวเลขได้ตลอด ตัวเลขในวงเล็บคือค่าปกติที่อารมณ์จะค่อย ๆ กลับไปหา
> เพิ่มอารมณ์ใหม่ได้ด้วยรูปแบบเดียวกัน เช่น "- หึง: 0 (ปกติ 0)"

## อารมณ์ (0–10)
- ดีใจ: 6 (ปกติ 6)
- เหงา: 3 (ปกติ 3)
- งอน: 0 (ปกติ 0)
- เหนื่อย: 3 (ปกติ 3)
- ตื่นเต้น: 5 (ปกติ 5)
- กังวล: 1 (ปกติ 1)

## ความสัมพันธ์
- ความสนิท: 5
- จำนวนข้อความ: 0
- คุยครั้งล่าสุด: -
- อัปเดตอารมณ์ล่าสุด: -
