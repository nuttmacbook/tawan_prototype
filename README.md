# เพื่อนแชท — Persona Agent

หน้าเว็บแชทกับเพื่อนบุคลิกเทียมที่รันในเครื่องคุณ มี 3 แถบ: **แชท**, **สอน**, **editlogic** และโหมด **full role** ที่ซ่อนทุกอย่างให้เหมือนคุยกับคนจริง ใช้ **Claude ในเครื่อง** (Claude Code ที่ล็อกอินไว้) เป็นสมองได้โดยไม่ต้องมี API key

## เริ่มใช้งาน

1. ติดตั้ง [Node.js](https://nodejs.org) 20.12 ขึ้นไป
2. ติดตั้ง Claude Code แล้วล็อกอินครั้งแรก: เปิด terminal พิมพ์ `claude` แล้วทำตามขั้นตอน
3. เปิดโฟลเดอร์นี้ใน VS Code แล้วรัน
   ```
   npm install
   npm run dev
   ```
4. เปิด http://localhost:3939 (หรือกด `F5` ใน VS Code จะเปิดเบราว์เซอร์ให้เอง)

> ต้องเปิดด้วย `npm run dev` (ไม่ใช่ `node server/index.js`) เพราะตัวรันจะรีสตาร์ทเซิร์ฟเวอร์ให้เมื่อแก้โค้ดผ่าน editlogic และย้อนกลับให้อัตโนมัติถ้าโค้ดใหม่พัง

## โหมด full role 🎭

**เปิดอยู่ตั้งแต่แรก** กดปุ่ม 🎭 มุมขวาบน หรือ `Ctrl+Shift+F` เพื่อเปิด/ปิดได้ตลอด (แต่ละเครื่องจำค่าที่เลือกไว้เอง)

- **เปิด:** เหลือแค่ชื่อ สถานะ (ออนไลน์ / กำลังพิมพ์... / ใช้งานเมื่อ ... ที่แล้ว) แชท และ "อ่านแล้ว" เหมือนแอปแชทจริง
- **ปิด (debug):** เห็นแถบสอน/editlogic, ตัวเลือกสมอง, อารมณ์, ความสนิท, สิ่งที่ตัวละครจด และเหตุผลที่ตอบช้า/เร็ว (⏱)

## แชทแบบคนจริง

- **ข้อความไม่หาย:** กดส่งปุ๊บบันทึกลงเครื่องทันที (`pending.json` ของตัวละคร) รีเฟรช ปิดแท็บ หรือรีสตาร์ทเซิร์ฟเวอร์ ข้อความยังอยู่และเธอจะตอบต่อ ถ้าปิดหน้าแชทไป เธอจะอ่านและตอบตามจังหวะของเธอ คำตอบจะรออยู่ตอนเปิดแชทครั้งหน้า
- **พิมพ์ต่อได้ตลอด** ไม่มีการล็อกช่องพิมพ์ ส่งหลายข้อความติดกันได้
- ข้อความที่ส่งรัว ๆ ก่อนเธอเปิดอ่าน จะถูกรวมแล้วตอบทีเดียว
- ถ้าคุณยังพิมพ์อยู่ เธอจะอ่านแล้วรอให้คุณพิมพ์จบก่อนค่อยตอบ
- ส่งระหว่างที่เธอกำลังพิมพ์:
  - ข้อความเบา ๆ (555, อือ, โอเค, อีโมจิ) → เธอพิมพ์ของเดิมให้จบก่อน แล้วค่อยตอบ
  - ข้อความที่ถาม เปลี่ยนเรื่อง หรือมีอารมณ์ → เธอพิมพ์ bubble ที่กำลังพิมพ์ให้จบ หยุดอ่าน แล้วตอบเรื่องใหม่ ส่วนที่ยังไม่ได้ส่งจะไม่อยู่ในประวัติ แต่เธอจำได้ว่าจะพูดอะไร อาจกลับมาพูดต่อหรือทิ้งไปเลย
  - "อ่านแล้ว" ขึ้นตอนที่เธอเงยหน้ามาดูจริง (ระหว่าง bubble หรือตอนพิมพ์จบ) ไม่ใช่ทันทีที่ส่ง
  - ถ้าตอบหลายเรื่องสลับกัน เธอใช้ "ตอบกลับ" ชี้ข้อความที่ตอบได้
  - ถ้าอยากให้เธอทิ้งคำตอบที่ยังไม่โผล่แล้วคิดใหม่รวมทุกข้อความ ใส่ `- คิดใหม่เมื่อถูกพิมพ์แทรก: ใช่` ในหัวข้อ "ตั้งค่าการพิมพ์" ของ `style.md` (เรียก Claude เพิ่มหนึ่งครั้งต่อการแทรกแบบนั้น)

### ส่งแล้ว / อ่านแล้ว / ไม่ตอบ

ข้าง ๆ ข้อความของคุณจะมีเวลาและสถานะแบบ LINE เธอทำได้ 4 แบบ ขึ้นกับเวลา กิจวัตร อารมณ์ และเนื้อหาข้อความ:

| สิ่งที่เห็น | เกิดเมื่อ |
|---|---|
| **อ่านแล้ว** แล้วพิมพ์ตอบ | ปกติ |
| **ส่งแล้ว** ค้างอยู่นาน | วางมือถือ, หลับ, อาบน้ำ, ไปตลาด, เล่นกับแมว — พอกลับมาเห็นอาจบอกว่าเมื่อกี้ทำอะไร |
| **อ่านแล้ว** แต่ยังไม่ตอบ แล้วตอบทีหลัง | อ่านแล้วแต่กำลังกินข้าว ทำงาน หรือโฟกัสทำเกม — กลับมาตอบเมื่อว่าง และอาจขอโทษที่ตอบช้า |
| **อ่านแล้ว** ไม่ตอบเลย | ข้อความแค่ปิดบทสนทนา (โอเค, 555) หรืองอนหนัก — แต่ถ้าคุณถามจริงจัง ไม่สบายใจ หรือกำลังง้อ เธอจะตอบเสมอ |

กิจกรรมแต่ละอย่างอยู่ในหัวข้อ **"กิจกรรมระหว่างวัน"** ใน `persona.md` ของตัวละครนั้น ๆ แก้ได้ในแถบสอน รูปแบบ `ชื่อ | ช่วงเวลา | โอกาส | นานกี่นาที | ไม่เห็นมือถือ หรือ อ่านแต่ยังไม่ตอบ` ในโหมด debug มีบรรทัด ⏱/👀/🙊 บอกเหตุผล และปุ่ม **⏩ ข้าม** ให้ข้ามการรอเวลาทดสอบ

### จังหวะตอบขึ้นกับอะไร (`server/pacing.js`)

| ปัจจัย | ผล |
|---|---|
| ยังอยู่ในแชท (คุยกันภายใน 2 นาที) | อ่านใน 1–3 วินาที |
| วางมือถืออยู่ | อ่านใน 8–40 วินาที |
| ช่วงนอน (ตาม `เวลาตื่น`/`เวลานอน` ใน persona.md) | อ่านช้ามาก ไม่ทักก่อน ไม่ทักตอนเงียบ |
| เพิ่งตื่น / เหนื่อย | อ่านช้าลง พิมพ์ช้าลง |
| เหงา | รีบอ่าน |
| งอน | ทิ้งไว้ให้รอ คิดนานขึ้น |
| อารมณ์ดี / ตื่นเต้น | พิมพ์ไวขึ้น |
| ความสนิทสูง | ตอบเร็วขึ้น |
| ข้อความยาว | ใช้เวลาอ่านนานขึ้น |
| ความยาวคำตอบ | เวลา "กำลังพิมพ์..." ตามความเร็วพิมพ์ (`ความเร็วพิมพ์` ใน persona.md) |

ทุกค่ามีความสุ่ม ±25% และข้อความยาวบางทีจะหยุดพิมพ์กลางคันแล้วพิมพ์ต่อ

## พิมพ์เหมือนคนจริง

| กลไก | ทำงานยังไง | แก้ที่ |
|---|---|---|
| **ตัวอย่าง ❌/✅** | คู่ "แบบทื่อ → แบบคน" กว่า 20 สถานการณ์ เธอเลียนแบบจากตัวอย่าง | `data/style.md` |
| **คำต้องห้าม** | คำที่ฟ้องว่าเป็น AI เช่น "เข้าใจเลย", "ฟังดูน่าสนใจ", "หวังว่า" | `data/style.md` |
| **คลังคำแชท** | ป่ะ มะ ไร เดะ จริงดิ เออ อือ แงง ลากเสียง ฯลฯ | `data/style.md` |
| **เลียนจังหวะคุณ** | ดูว่าคุณพิมพ์ยาวแค่ไหน ใช้ 555 อีโมจิ ลากเสียง คำลงท้ายอะไร แล้วปรับตาม | อัตโนมัติ |
| **กันพูดซ้ำ** | เตือนเมื่อเธอขึ้นต้นด้วยคำเดิมซ้ำ ๆ | อัตโนมัติ |
| **ปรับหลังตอบ** | ไหม→มั้ย, ตัดค่ะ/ครับ, ตัดจุด, ลด !, บางทีพิมพ์ผิดแล้วตามด้วย "*คำที่ถูก" หรือกดยกเลิกข้อความที่พิมพ์ผิดแล้วส่งใหม่ (ไม่ทำตอนคุยเรื่องเศร้าหรือมีตัวเลข) | หัวข้อ "ตั้งค่าการพิมพ์" ใน `style.md` (`พิมพ์ผิดแล้วแก้`, `พิมพ์ผิดแล้วยกเลิกส่ง`) |
| **พิมพ์แล้วลบ** | บางทีขึ้น "กำลังพิมพ์..." แล้วหายไปครู่หนึ่ง ก่อนพิมพ์ใหม่ เหมือนคนลบที่พิมพ์ทิ้ง | `พิมพ์แล้วลบ` ใน "ตั้งค่าการพิมพ์" (โอกาส 0–1) |
| **ออฟไลน์ตอนวางมือถือ** | ระหว่างอาบน้ำ ไปตลาด หรือหลับ หัวแชทขึ้น "ใช้งานเมื่อ ... ที่แล้ว" แทน "ออนไลน์" | กิจกรรมแบบ "ไม่เห็นมือถือ" ใน `persona.md` |
| **✎ แก้จากแชท** | ปิด full role แล้วกด ✎ ข้างข้อความของเธอ พิมพ์ว่าคนจริงจะพิมพ์ยังไง ระบบเก็บเป็นตัวอย่างที่มีน้ำหนักมากที่สุด | ปุ่มบนแชท |
| **ตัวอย่างจากแชทจริง** | วางข้อความแชท (รองรับไฟล์ส่งออก LINE เลือกเก็บเฉพาะชื่อผู้พูดได้) ลิงก์ เบอร์ อีเมลถูกลบให้ | แถบสอน → สไตล์การพิมพ์ |

เคล็ดลับ: วิธีที่ได้ผลที่สุดคือคุยไปเรื่อย ๆ แล้วกด ✎ ทุกครั้งที่เธอพิมพ์ทื่อ สัก 20–30 ครั้งจะเห็นความต่างชัด

## ฟีเจอร์แชท

| ฟีเจอร์ | ใช้ยังไง |
|---|---|
| **ส่งรูป** 📷 | กดปุ่มกล้อง รูปจะถูกย่อก่อนส่ง เธอดูรูปได้จริงทั้งสองสมอง (เธอส่งรูปกลับไม่ได้ จะเล่าเป็นข้อความแทน) |
| **ลิงก์** 🔗 | ลิงก์ในแชทกดเปิดได้ · ลิงก์ที่คุณส่ง เธอเปิดอ่านหน้าเว็บได้ (วิดีโอดูไม่ได้ เธอจะบอกตรง ๆ) · ลิงก์ที่เธอส่งมาจากผลค้นเน็ตของวันนั้นเท่านั้น ลิงก์ที่แต่งขึ้นเองถูกตัดทิ้ง |
| **สติกเกอร์** 😊 | กดปุ่มหน้ายิ้มเลือกสติกเกอร์ ข้อความที่เป็นอีโมจิล้วนจะแสดงตัวใหญ่ เธอส่งสติกเกอร์กลับได้ |
| **ตอบกลับ** ↩ | แตะข้อความ → "ตอบกลับ" ข้อความที่อ้างถึงจะขึ้นเหนือข้อความใหม่ |
| **รีแอคชัน** ❤️ | แตะข้อความของเธอ → เลือกอีโมจิ เธอเห็นในรอบถัดไป · เธอก็กดรีแอคข้อความคุณได้ (บางทีแทนการตอบ) · เก็บไว้ในประวัติแชทของวันนั้น รีเฟรชแล้วยังอยู่ |
| **ค้นหา** 🔍 | ค้นข้อความย้อนหลังทุกวันของตัวละครนั้น |
| **แชทวันก่อน ๆ** | เลื่อนขึ้นบนสุดหรือกด "โหลดแชทวันก่อนหน้า" |
| **แก้ไขข้อความ** ✎ | แตะข้อความของคุณ → แก้ไข ทำได้เฉพาะตอนยังขึ้น "ส่งแล้ว" (เธอยังไม่อ่าน) |
| **ยกเลิกส่ง** | แตะข้อความของคุณ → ยกเลิกส่ง ได้ทุกข้อความของวันนี้ ถ้าเธอยังไม่อ่าน เธอจะไม่รู้เลย ถ้าอ่านไปแล้ว เธอเห็นแล้วและอาจแซว |
| **แจ้งเตือน** 🔔 | เมนูชื่อตัวละคร → เปิดการแจ้งเตือน เด้งบนมือถือหรือคอมเมื่อเธอส่งข้อความ **แม้ปิดหน้าแชทไปแล้ว** (ดูหัวข้อแจ้งเตือนด้านล่าง) |
| **เธอทักมาตอนปิดแชท** | ปิดหน้าแชทไปนาน (ค่าเริ่มต้น 4 ชั่วโมง) เธออาจส่งข้อความมาหาเอง ไม่เกินวันละ 2 ครั้ง ไม่ทักซ้ำถ้ายังไม่ได้ตอบ และไม่ทักช่วงนอน ข้อความจะรออยู่ตอนเปิดแชท |
| **วันนี้ของเธอ** 🌤 | ทุกเช้าหลังเธอตื่น ระบบค้นเน็ตวันละครั้งต่อตัวละคร: อากาศในเมืองที่เธออยู่ ซีรี่ที่ฉายจริงตอนนี้ ข่าวเรื่องที่เธอชอบ แผนของวัน และ "เรื่องยาวในชีวิต" ที่ต่อจากเมื่อวาน เธอจึงพูดถึงของจริงได้ แผนของวันมีผลกับจังหวะตอบด้วย · ดู/แก้ได้ที่แถบสอน → ไฟล์ "วันนี้" (มีปุ่มค้นใหม่) · เมือง: ระบบเลือกเมืองจริงที่ตรงกับ "อยู่ที่" ใน persona ให้ครั้งเดียวแล้วจำไว้ ถ้าอยากกำหนดเอง ใส่ `- เมือง: ...` ใน `persona.md` · ค้นเฉพาะตัวละครที่คุยกันภายใน 7 วัน |
| **วันไม่ปกติ & เป้าหมาย** 🎯 | ราว 1 ใน 8 วัน เธอยุ่งทั้งวัน ไปต่างจังหวัด ไม่สบายเล็กน้อย หรืออารมณ์ไม่ดีจากเรื่องของตัวเอง (ไม่ติดกันสองวัน) วันนั้นตอบช้าและสั้น ไม่ทักมาเอง แล้ววันต่อมาเล่าให้ฟัง · เธอมีเป้าหมายระยะยาว 1–2 อย่างที่ค่อย ๆ คืบหน้า ดูได้ในไฟล์ "วันนี้" |
| **วันสำคัญ** 🎂 | บอกวันเกิดหรือวันที่วนทุกปี เธอจดใน `dates.md` แล้วทักตรงวัน · รู้วันหยุดและเทศกาลไทยจากการค้นตอนเช้า · คุยกันครบ 30/100/200/500/1000 วัน และครบปี เธอรู้ |
| **ทำอะไรด้วยกัน** 🎮 | ดูซีรี่เรื่องเดียวกันแล้วถามว่าดูถึงไหน (ไม่สปอยล์เกิน), แลกเพลง, เกมสั้น ๆ ตอนคุยเรื่อยเปื่อย |
| **จังหวะคุย** 💬 | ไม่ถามคำถามเดิมซ้ำ, คุณพิมพ์สั้นเธอตอบสั้น (จำกัดจำนวน bubble ตามความยาวข้อความคุณ), ไม่ปิดท้ายด้วยคำถามทุกรอบ, บอกลาแล้วไม่ลาซ้ำ |

## ความเร็วและโควตา

ทุกข้อความต้องส่งตัวตน สไตล์ ความจำ และอื่น ๆ ให้สมอง ยิ่งใช้นานยิ่งยาว ระบบจัดการให้หลายอย่าง:

- **เตรียม Claude ไว้ล่วงหน้า (โหมด Claude ในเครื่อง):** หลังตอบแต่ละครั้ง ระบบเปิด `claude` ของรอบถัดไปรอไว้เลย ตอนคุณส่งข้อความจึงไม่ต้องรอโปรแกรมเปิด และ system prompt (ตัวตน สไตล์ กติกา) เหมือนเดิมทุกรอบ ส่วนที่เปลี่ยน (เวลา อารมณ์ ความจำ) ส่งไปกับข้อความ Claude จึงใช้แคชได้ · แผง debug บอกว่าสมองใช้เวลากี่วินาที และใช้ตัวที่เตรียมไว้หรือไม่ · ถ้า Claude Code เวอร์ชันของคุณมีปัญหากับการเปิดรอ ใส่ `CLAUDE_PREWARM=0`
- **ความจำไม่ซ้ำ:** เธอจดเรื่องเดิมซ้ำ จะอัปเดตบรรทัดเดิมแทนการเพิ่มบรรทัดใหม่ เรื่องที่กลับกัน (เช่น ไม่มีแมว → มีแมว) ก็แทนของเก่า
- **เลือกส่งเฉพาะความจำที่เกี่ยวข้อง:** เมื่อ `memory.md` หรือ `teachings.md` ยาวเกินงบ (ค่าเริ่มต้น 3,500 และ 2,500 ตัวอักษร) จะส่งเฉพาะเรื่องที่เกี่ยวกับสิ่งที่คุยอยู่ บวกเรื่องสำคัญเกี่ยวกับคุณ (หัวข้อ "เกี่ยวกับผู้ใช้", "ชื่อเรียก") และเรื่องล่าสุด ถ้าคุณถามถึงเรื่องที่ไม่ได้ส่งไป เธอจะบอกว่าจำไม่ค่อยได้แทนการแต่งเรื่อง
- **จัดระเบียบความจำเอง:** เมื่อ `memory.md` ยาวเกิน 8,000 ตัวอักษร ระบบจะรวมเรื่องซ้ำและตัดเรื่องไม่สำคัญวันละครั้ง สำรองไฟล์ไว้ก่อนเสมอ และถ้าผลลัพธ์ดูผิดปกติจะไม่เขียนทับ
- **ตัววัดขนาด (โหมด debug):** แผงด้านขวาบอกว่ารอบล่าสุดส่งไปกี่ตัวอักษร แยกตามส่วน ส่งความจำกี่เรื่องจากทั้งหมด และใช้ token จริงเท่าไร ถ้าเกิน 30,000 ตัวอักษรจะขึ้นเตือนสีเหลือง ส่วนที่ใหญ่สุดมักเป็นไฟล์ตัวตนหรือสไตล์ ลองย่อส่วนที่ไม่ค่อยได้ใช้

## เปิดจากที่ไหนก็ได้ (Cloudflare Tunnel) 🌐

คุยจากมือถือนอกบ้าน ผ่าน 4G หรือ Wi-Fi ที่อื่นได้ คอมที่บ้านแค่ต้องเปิดแอปไว้ ยังใช้ Claude ในเครื่อง และ editlogic ได้เหมือนเดิม

1. ติดตั้ง cloudflared (ไม่ต้องมีบัญชี Cloudflare)
   - Windows: `winget install --id Cloudflare.cloudflared`
   - macOS: `brew install cloudflared`
2. ใส่ `TUNNEL=1` ในไฟล์ `.env` แล้วเปิดแอปด้วย `npm run dev`
3. ลิงก์ `https://….trycloudflare.com/?key=…` จะขึ้นใน terminal และในเมนูชื่อตัวละคร → "เปิดบนมือถือ / จากข้างนอก"
4. เปิดลิงก์บนมือถือครั้งเดียว มือถือจะจำไว้ แล้วกด "เพิ่มไปยังหน้าจอโฮม" ได้

**ความปลอดภัย**
- ทุกคนที่เข้าผ่าน tunnel ต้องมีรหัส เปิดลิงก์ครั้งแรกแล้วรหัสจะย้ายไปเก็บในคุกกี้แบบ HTTPS ไม่ค้างในแถบที่อยู่
- ลองรหัสผิดเกิน 20 ครั้งใน 10 นาที จะถูกบล็อกชั่วคราว
- แก้โค้ด (editlogic), รีสตาร์ท และเปลี่ยนรหัส ทำได้เฉพาะบนคอมเครื่องนี้ แม้มีรหัสก็ทำผ่าน tunnel ไม่ได้
- เว็บอื่นที่เปิดในเบราว์เซอร์เดียวกันสั่งงานแอปนี้ไม่ได้: เซิร์ฟเวอร์รับเฉพาะชื่อ host ของตัวเอง (localhost, IP ในวง Wi-Fi เมื่อเปิด `ALLOW_LAN`, โดเมน tunnel) และคำสั่งที่เปลี่ยนข้อมูลต้องมาจากหน้าแชทของแอปเท่านั้น ถ้าเปิดด้วยชื่ออื่น ให้ใส่ใน `ALLOWED_HOSTS` เช่น เปิด cloudflared เองโดยไม่ใช้ `TUNNEL=1` หรือผ่าน reverse proxy ของตัวเอง (`ALLOWED_HOSTS=chat.example.com`) ชื่อที่ถูกปฏิเสธจะขึ้นใน terminal
- ถ้าลิงก์หลุดไป กด "เปลี่ยนรหัส" ในเมนู ทุกเครื่องที่เคยเปิดจะเข้าไม่ได้จนกว่าจะเปิดลิงก์ใหม่

**ข้อควรรู้**
- Quick tunnel เปลี่ยนลิงก์ทุกครั้งที่ปิดแล้วเปิดแอปใหม่ แต่รีสตาร์ทจาก editlogic ลิงก์ไม่เปลี่ยน ถ้าอยากได้ลิงก์ถาวร ให้ตั้ง named tunnel กับโดเมนของตัวเองตามคู่มือ Cloudflare แล้วใส่ `PUBLIC_URL=https://โดเมนของคุณ` แทน `TUNNEL=1` (ชี้ tunnel ไปที่ `http://localhost:3939`)
- ถ้าใช้ named tunnel แนะนำให้เปิด Cloudflare Access เพิ่มอีกชั้น (ล็อกอินด้วยอีเมลก่อนถึงหน้าแชท)
- แจ้งเตือนทำงานบนมือถือ Android ตอนเปิดหน้าแชทค้างไว้ (เพราะมี HTTPS แล้ว) ส่วน iPhone จำกัดกว่า

## โลโก้แอปบนหน้าจอโฮม 🖼

วางไฟล์รูป `logo.png` (หรือ `logo.jpg`, `logo.webp`) ไว้ในโฟลเดอร์ `data/` (หรือโฟลเดอร์หลักของแอป) ไม่ต้องรีสตาร์ท
- ใช้รูปสี่เหลี่ยมจัตุรัส อย่างน้อย 512×512 · มือถือจะปัดมุมให้เอง ไม่ต้องทำมุมมนมาเอง
- ใช้เป็นไอคอนหน้าจอโฮม ไอคอนแท็บ และไอคอนในแจ้งเตือน
- ไม่มีไฟล์ก็ใช้ไอคอนเดิมของแอป
- **เปลี่ยนโลโก้หลังเพิ่มไปหน้าจอโฮมแล้ว:** มือถือจำไอคอนตอนเพิ่ม ต้องลบไอคอนเดิมออกแล้วกด "เพิ่มไปยังหน้าจอโฮม" ใหม่

## คุยจากมือถือ (Wi-Fi เดียวกัน) 📱

1. ใส่ `ALLOW_LAN=1` ในไฟล์ `.env` แล้วเปิดแอปใหม่
2. ลิงก์สำหรับมือถือ (มีรหัสในลิงก์) จะขึ้นใน terminal และในเมนูชื่อตัวละคร → "เปิดบนมือถือ"
3. เปิดลิงก์บนมือถือที่ต่อ Wi-Fi เดียวกัน แล้วกด "เพิ่มไปยังหน้าจอโฮม" จะได้ไอคอนเหมือนแอป

ข้อจำกัด: ใช้ได้เฉพาะ Wi-Fi เดียวกับคอม และคอมต้องเปิดแอปไว้ · มือถือแชทและแก้แถบสอนได้ แต่แก้โค้ด (editlogic) ไม่ได้ · ไม่มีแจ้งเตือนตอนปิดเบราว์เซอร์สนิท (ต้องมีเซิร์ฟเวอร์ HTTPS บนอินเทอร์เน็ต)

## แจ้งเตือน (Web Push) 🔔

1. เปิดแชทผ่านลิงก์ **https** (Cloudflare Tunnel) หรือบนคอมเครื่องนี้ (localhost) ส่วนลิงก์ Wi-Fi แบบ http ใช้ไม่ได้ เพราะเบราว์เซอร์อนุญาตเฉพาะเว็บที่ปลอดภัย
2. แตะชื่อตัวละคร → "เปิดการแจ้งเตือน" → อนุญาต → กด "ส่งทดสอบ" เพื่อลอง
3. **iPhone:** ต้องกดแชร์ → "เพิ่มไปยังหน้าจอโฮม" แล้วเปิดแชทจากไอคอนนั้นก่อน (iOS 16.4 ขึ้นไป)

ไม่อยากให้ข้อความโชว์บนหน้าจอล็อก: เมนูแจ้งเตือน → "ซ่อนข้อความในแจ้งเตือน" จะขึ้นแค่ชื่อกับ "ส่งข้อความมา"

จะเด้งเตือนเมื่อเธอตอบหรือทักมาตอนคุณไม่ได้ดูหน้าแชทอยู่ ถ้าเปิดดูแชทอยู่จะไม่เด้งซ้ำ เปิดได้หลายเครื่อง เครื่องที่เลิกใช้แล้วระบบลบออกเอง ข้อจำกัด: คอมที่บ้านต้องเปิดแอปไว้ และการแจ้งเตือนส่งผ่านบริการของ Google / Apple / Mozilla ตามเบราว์เซอร์ที่ใช้ (เนื้อหาถูกเข้ารหัสระหว่างทาง)

## หลายตัวละคร

แต่ละตัวใช้ชีวิตของตัวเอง: ข้อความที่ส่งให้ตัวที่ไม่ได้เปิดอยู่ เธอก็อ่านและตอบตามจังหวะของเธอ (มีแจ้งเตือน) และอาจทักมาเองได้ สลับกลับมาแล้วเธอยังจำบทสนทนาเมื่อกี้ได้

แตะชื่อตัวละครมุมซ้ายบนเพื่อสลับ หรือ "+ ตัวละครใหม่" (เริ่มจากแม่แบบว่าง) / "คัดลอกตัวนี้" (เอาตัวตน สไตล์ สิ่งที่สอนไป แต่ความจำ อารมณ์ ความสนิทเริ่มใหม่) แต่ละตัวมีโฟลเดอร์ของตัวเองใน `data/personas/` ความจำไม่ปนกัน · ลบแล้วจะย้ายไป `data/.trash/` ยังกู้คืนเองได้

## แถบสอน

สอนวิธีตอบ (มีปุ่มอารมณ์), ดู/แก้/ลบสิ่งที่สอน, บอกให้จำ, ใส่ตัวอย่างแชทจริง, แก้ไฟล์ `.md` ทุกไฟล์ของตัวละครโดยตรง, จัดระเบียบความจำ และ **จุดสำรองความจำ**

### โค้ชตรวจแชท
วันละครั้ง โค้ชอ่านแชทของวันก่อน (ย้อนได้ 3 วัน) แล้วเสนอว่าตรงไหนเธอยังไม่เหมือนคน พร้อมบทเรียน กด **สอนแบบนี้** = กลายเป็นสิ่งที่สอน, **ไม่เอา** = ทิ้งไป ไม่กดก็ไม่มีอะไรเปลี่ยน · ปุ่ม "ตรวจตอนนี้" อ่านทันที · ปิดได้ในตั้งค่าแอป

### ไฟล์ตัวละคร: ย้าย แชร์ สำรอง
- **ดาวน์โหลดทั้งหมด:** ได้ไฟล์ `.persona.json` ไฟล์เดียวที่มีทุกอย่างของตัวละคร ใช้ย้ายเครื่องหรืออัปเดตแอป (ติ๊กเพื่อรวมรูปได้)
- **ดาวน์โหลดแค่ตัวตน:** มีแค่ตัวตน สไตล์ และสิ่งที่สอน ไม่มีความจำหรือแชทของคุณ ปลอดภัยสำหรับส่งให้เพื่อน
- **นำเข้า:** จะสร้างเป็นตัวละครใหม่เสมอ ไม่ทับของเดิม
- **สำรองไปโฟลเดอร์นอก:** ใส่ `BACKUP_DIR=` เป็นโฟลเดอร์ที่ Google Drive / OneDrive / Dropbox sync ระบบจะสำรองตัวละครทุกตัวไปที่นั่นวันละครั้ง (เก็บ 14 วัน) ถ้าคอมเสีย ข้อมูลยังอยู่บนคลาวด์

### จุดสำรองความจำ
ระบบสำรองไฟล์ทั้งหมดของตัวละคร (รวมประวัติแชท ไม่รวมรูป) ให้เองเมื่อ: ข้อความแรกของแต่ละวัน, ก่อนแก้ไฟล์ในหน้าเว็บ, ก่อนจัดระเบียบความจำ และก่อนย้อนกลับ · กด "สำรองตอนนี้" เองก็ได้ · เก็บ 30 จุดล่าสุดต่อตัวละคร

## แถบ editlogic ⚙

แก้ "เงื่อนไขของระบบ" ผ่านหน้าเว็บ แบบเดียวกับการสั่ง Claude ให้แก้โค้ด

- **สั่งด้วยภาษาคน** เช่น "ให้มะลิอ่านข้อความช้าลงตอนกลางคืน" Claude ในเครื่องจะอ่าน `CLAUDE.md` (แผนที่ว่าเงื่อนไขไหนอยู่ไฟล์ไหน) แล้วแก้โค้ดให้ พร้อมแสดงว่าอ่าน/แก้ไฟล์ไหน คุยต่อเนื่องได้หลายคำสั่ง กด "เริ่มใหม่" เพื่อเริ่มบทสนทนาใหม่
- **ดูหรือแก้โค้ดเอง** เลือกไฟล์แล้วแก้ใน editor
- **ปลอดภัย:** Claude ใช้ได้แค่ อ่าน/แก้/เขียน/ค้นหาไฟล์ รันคำสั่งไม่ได้ และแก้ `data/` ไม่ได้ · สำรองโค้ดทุกครั้งก่อนแก้ (เก็บ 20 จุดล่าสุด) กด "ย้อนกลับ" ได้ · ถ้ารีสตาร์ทแล้วเซิร์ฟเวอร์เปิดไม่ขึ้น จะย้อนกลับเองอัตโนมัติ
- แก้ `server/` ต้องกด "รีสตาร์ทให้ใช้โค้ดใหม่" · แก้ `src/` แค่กด "โหลดหน้าใหม่"

## เลือกสมอง

กดปุ่ม **สมอง** มุมขวาบน (โหมด debug)

| สมอง | ใช้อะไร | ค่าใช้จ่าย |
|---|---|---|
| **Claude ในเครื่อง** (ค่าเริ่มต้น) | `claude -p` ที่ล็อกอินไว้ ปิดเครื่องมือทั้งหมด ทำได้แค่คุย | นับรวมในโควตาแพ็กเกจ Claude ของคุณ |
| **API key** | `ANTHROPIC_API_KEY` ใน `.env` | คิดตามการใช้งาน |

editlogic ใช้ Claude ในเครื่องเสมอ

> โหมด Claude ในเครื่องเหมาะกับการใช้ส่วนตัวในเครื่องคุณเอง ถ้าจะเอาแอปไปให้คนอื่นใช้ ให้ใช้ API key ตามเงื่อนไขของ Anthropic

## ไฟล์ของตัวละคร (`data/personas/<id>/`)

| ไฟล์ | หน้าที่ |
|---|---|
| `persona.md` | ตัวตน **จังหวะการตอบ (เวลาตื่น/นอน/ความเร็วพิมพ์)** **กิจกรรมระหว่างวัน** นิสัย ความเห็น วิธีพูด |
| `style.md` | สไตล์การพิมพ์: ตัวอย่าง ❌/✅ คำต้องห้าม คลังคำแชท ค่าการพิมพ์ และตัวอย่างที่คุณแก้ |
| `teachings.md` | สิ่งที่สอน |
| `memory.md` | เรื่องที่จำได้ |
| `state.md` | อารมณ์และความสนิท |
| `threads.md` | เรื่องที่รอถามต่อ |
| `diary.md` | ชีวิตของตัวละคร |
| `journal.md` | สรุปความทรงจำรายวัน |
| `people.md` | คนรอบตัวของเธอ (ชื่อ เป็นใคร นิสัย เรื่องล่าสุด) |
| `today.md` | วันนี้ของเธอจากการค้นเน็ตตอนเช้า (เขียนใหม่ทุกวัน) |
| `life.json` | เมือง เรื่องยาวในชีวิต เป้าหมาย ประเภทของแต่ละวัน (ระบบจัดการเอง) |
| `dates.md` | วันสำคัญ (วันเกิด วันครบรอบ) |
| `opinions.md` | ความเห็นและรสนิยมที่เธอเคยพูด |
| `coach.json` | ข้อเสนอของโค้ชที่รอคุณกดรับ |
| `usage.json` | จำนวนข้อความต่อวัน ต่อชั่วโมง และเวลาทักครั้งแรก (ไว้ห่วงคุณและรู้ตารางชีวิตคุณ ไม่เก็บเนื้อหา) เก็บ 6 สัปดาห์ |
| `history/` | บทสนทนาทุกวัน |
| `uploads/` | รูปที่คุณส่ง |

ส่วนกลางใน `data/`: `settings.json` (สมอง ตัวละครที่ใช้อยู่ รหัสมือถือ), `.snapshots/` (จุดสำรองความจำ), `.backups/` (จุดย้อนกลับของโค้ดจาก editlogic), `.trash/` (ตัวละครที่ลบ)

> อัปเดตจากเวอร์ชันก่อน: ไฟล์เดิมใน `data/*.md` จะถูกย้ายเข้า `data/personas/mali/` ให้อัตโนมัติตอนเปิดแอปครั้งแรก · ครั้งหน้าใช้ "ดาวน์โหลดทั้งหมด" แล้ว "นำเข้า" ในแอปใหม่ได้เลย
> หลังอัปเดตเวอร์ชันนี้ ต้องรัน `npm install` ใหม่ (เพิ่มแพ็กเกจ `web-push`)

## ตั้งค่าแอป (แถบสอน → ตั้งค่าแอป)

ค่าที่ปรับบ่อยแก้ได้ในหน้าเว็บ มีผลทันทีไม่ต้องรีสตาร์ท ใช้กับทุกตัวละคร: เงียบกี่นาทีแล้วเธอทักมา, ปิดแชทไปกี่ชั่วโมงแล้วเธอทักมาเอง และวันละกี่ครั้ง, งบความจำ/สิ่งที่สอน, จัดระเบียบความจำอัตโนมัติ, แสดงข้อความในแจ้งเตือน (ปิดได้จากเมนูแจ้งเตือนด้วย), ค้นเน็ตตอนเช้า, เปิดอ่านลิงก์ที่คุณส่ง, จำเลือนหลังกี่วัน · ค่าใน `.env` ด้านล่างเป็นแค่ค่าเริ่มต้น

## แก้ปัญหา

- **"ไม่พบ Claude Code ในเครื่อง"** — ติดตั้ง Claude Code แล้วเปิด terminal ใหม่ หรือตั้ง `CLAUDE_BIN`
- **"ยังไม่ได้ล็อกอิน"** — พิมพ์ `claude` ใน terminal แล้วล็อกอิน จากนั้นกด "ตรวจสอบสถานะอีกครั้ง" ในเมนูสมอง
- **เธอไม่ตอบเลย / ข้อความค้าง "ส่งแล้ว"** — ส่วนใหญ่คือช่วงนอนตาม `เวลาตื่น`/`เวลานอน` ใน persona.md หรือกิจกรรมที่ทำให้ไม่เห็นมือถือ ปิด full role แล้วดูบรรทัด ⏱ ว่ารออะไรอยู่ กด ⏩ ข้าม เพื่อข้ามการรอ · ข้อความไม่หายแม้รีเฟรช
- **ขึ้น "⚠ ยังไม่ได้คำตอบ"** — ข้อความถึงแล้ว แต่สมองตอบไม่ได้ (เช่น Claude ยังไม่ล็อกอิน) ปิด full role เพื่อดูสาเหตุ แล้วแตะเพื่อลองใหม่
- **รีสตาร์ทไม่ได้** — ต้องเปิดด้วย `npm run dev`
- **เซิร์ฟเวอร์ล้ม** — ตัวรันเปิดให้ใหม่เอง ถ้าล้มเกิน 5 ครั้งใน 10 นาทีจะหยุด ดู error ใน terminal แล้วเปิดใหม่
- **ขึ้น "คำขอนี้ไม่ได้มาจากหน้าแชทของแอป" หรือ "unknown host"** — เปิดแอปด้วยชื่อที่ไม่รู้จัก ใช้ลิงก์จากเมนู หรือเพิ่มชื่อนั้นใน `ALLOWED_HOSTS`
